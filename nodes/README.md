# Custom N8N Nodes

This directory is for custom node definitions if needed.

## Creating Custom Nodes

If you need custom functionality not available in standard N8N nodes:

1. Create node definition files here
2. Follow N8N node development guidelines
3. Test thoroughly before using in production workflows
