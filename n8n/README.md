# N8N Workflows

This directory contains N8N workflow configurations for the Quiz Bank Generator project.

## Structure

- `workflows/` - N8N workflow JSON files
- `credentials/` - Credential configuration templates (do not commit actual credentials)
- `nodes/` - Custom node definitions (if any)
- `docker-compose.yml` - Docker setup for local N8N instance

## Setup

1. Install N8N:
   ```bash
   npm install n8n -g
   ```

2. Start N8N:
   ```bash
   n8n start
   ```

3. Import workflows from the `workflows/` directory
